# Лабораторная 3. Unsupervised Кластеризация смартфонов.

## Цель проекта
Разработать и сравнить алгоритмы кластеризации для автоматической сегментации смартфонов на основе их технических характеристик и цены.

## О датасете
- **1262 смартфона** из каталога DNS
- **13 ключевых признаков**: цена, RAM, память, батарея, камера, рейтинг и др.
- **Сбалансированные сегменты** по соотношению цена/качество

## Результаты

### Качество моделей
| Модель | Silhouette | Улучшение vs Baseline | Кластеры |
|--------|------------|---------------------|----------|
| Собственный K-means | **0.2795** | **+355.5%** | 5 |
| Sklearn K-means | 0.2861 | +366.0% | 6 |
| Baseline (price-based) | 0.0614 | - | 5 |

### Достижения
- Качество на уровне sklearn (разница всего 2.3%)
- В 16.7 раз быстрее сходимости (6 итераций vs 100)
- Почти идеальное соответствие кластеров (ARI = 0.9366)
- 5/5 критериев успешности выполнены

## Особенности реализации

### Собственный K-means включает:
- Два метода инициализации (random, k-means++)
- Контроль сходимости по изменению центроидов
- Визуализацию процесса обучения
- Оптимизацию гиперпараметров

### Метрики качества:
- **Silhouette Score** - компактность и разделимость кластеров
- **Calinski-Harabasz** - отношение межкластерной/внутрикластерной дисперсии  
- **Davies-Bouldin** - схожесть кластеров
- **Adjusted Rand Index** - соответствие с sklearn

## Выводы
Собственная реализация K-means успешно решает задачу кластеризации, показывая качество на хорошем уровне. Алгоритм эффективно выявляет рыночные сегменты.
