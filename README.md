# Лабораторная 2. Supervised

## Цель проекта
Разработать модель машинного обучения для классификации смартфонов на основе композитного таргета "Индекс ценности покупки", который оценивает соотношение характеристик устройства к его стоимости.

### Файл analysis.ipynb содержит аналитику по датасету. Файл main.ipynb реализует модели.

## Данные
- **Источник**: Парсинг сайта DNS (категория смартфоны)
- **Объем**: 1,262 смартфона
- **Признаки**: 24 фичера после обработки (ценовые, технические характеристики, рейтинги)
- **Целевая переменная**: 5 категорий ценности

### Категории ценности:
- `poor_value` - Низкая ценность
- `average_value` - Средняя ценность  
- `good_value` - Хорошая ценность
- `great_value` - Отличная ценность
- `exceptional_value` - Исключительная ценность

## Технический стек
- **Python 3.12**
- **Библиотеки**: pandas, numpy, scikit-learn, matplotlib, seaborn, jupyter
- **Модели**: Random Forest (Sklearn + кастомная реализация)

## Основные этапы работы

### 1. Предобработка данных
- Очистка пропущенных значений
- Извлечение признаков из текстовых полей (specs_raw)
- Создание новых features:
  - Процент скидки
  - Плотность пикселей
  - Логарифм цены
  - Общий score характеристик

### 2. Baseline модель
- **Наивный классификатор**: всегда предсказывает самый частый класс
- **Accuracy**: 0.253
- **Цель**: установить минимальный порог для ML моделей

### 3. Machine Learning модели

#### Sklearn Random Forest
- **Базовая модель**: Accuracy = 0.957
- **С подбором параметров**: Accuracy = 0.957
- **Лучшие параметры**:
  ```python
  {
      'n_estimators': 200,
      'max_depth': 20, 
      'min_samples_split': 2,
      'min_samples_leaf': 1,
      'max_features': 'sqrt'
  }
  ```

#### Кастомный Random Forest
- **Самостоятельная реализация** с 3 гиперпараметрами
- **Базовая версия**: Accuracy = 0.913
- **С подбором параметров**: Accuracy = 0.933
- **Лучшие параметры**: (50 деревьев, глубина 10, min_samples_split=2)

## Результаты

### Сравнение моделей
| Модель | Accuracy | Улучшение над Baseline |
|--------|----------|------------------------|
| Baseline (Наивный) | 0.253    | -                      |
| Sklearn RF (Базовая) | 0.957    | +0.704                 |
| Sklearn RF (Оптимизированная) | 0.957    | +0.704                 |
| Custom RF (Базовая) | 0.921    | +0.668                 |
| Custom RF (Оптимизированная) | 0.945    | +0.692                 |

### Ключевые метрики качества
- **Лучшая модель**: Sklearn Random Forest (0.957 accuracy)
- **Переобучение**: минимальное (разница train/val < 0.05)
- **Обобщающая способность**: отличная

### Важность признаков
1. **features_score** (27.7%) - общий score характеристик
2. **storage_gb** (13.5%) - объем памяти
3. **ram_gb** (7.9%) - оперативная память
4. **price** (6.3%) - цена
5. **price_per_feature** (5.3%) - цена за единицу характеристик
